# 抖音样本分析与证据门槛

日期：2026-10-19（Asia/Shanghai）。样本来自本次用户消息。遵循仓库既有脱敏规则，不在文档持久化完整短链 token、作品 ID、查询参数、Cookie、媒体签名 URL 或原始页面。

当前结果见[实现验收证据](implementation-evidence-2026-10-20.md)：受控浏览器已在新的匿名上下文中自动取得 V1、V2 普通视频和 I1 的完整静态图文，代表媒体通过独立读取；I2 的唯一图片槽位含动态 MP4，按首版范围返回 `UNSUPPORTED_CONTENT`。早期 HTTP 与浏览器观察保留在 [P0 实测](p0-data-loading-2026-10-19.md)，下文继续保留首次探测历史。

## 首次探测历史（不代表当前状态）

1. 网页检索工具分别打开四个 `https://v.douyin.com/<token>/`，均返回该工具无法访问 URL；没有得到 HTTP 状态、重定向或正文。
2. 本机进行了不保存正文的有界探测尝试，预设逐跳精确主机校验、公网 DNS 检查、TLS 校验、3 次跳转和 2 MiB 读取上限。共享起始域名 `v.douyin.com` 在系统 DNS 查询阶段抛出 `socket.gaierror: [Errno 8]`，探测批次提前终止，没有拿到可用于分析的 HTTP 响应。
3. 本机当前 Python 环境未安装 `curl_cffi`，没有为本次文档任务安装依赖；本地探测准备使用系统 curl，未完成现有生产客户端指纹的等价验证。

因此不能声称四条链接失效、被抖音反爬拦截或已解析成功，也不能推导真实跳转域名、图数、视频质量及水印状态。

## 历史实施门槛

| 项目 | 需要记录的脱敏证据 | 不通过时的处理 |
| --- | --- | --- |
| 短链跳转 | 实际主机/路径模板、状态、跳数、查询参数键；不留值 | 环境 DNS 问题先排除；未知主机不得自动放行 |
| 匿名作品数据 | 新匿名会话能得到目标作品，ID 与 URL 相符；定位状态容器 | 登录/挑战如实记录；不能只完成错误返回便宣称功能验收 |
| 视频 | 主视频 MP4 的明确证据、可选封面、元数据单位 | 只有 HLS/音频/含糊播放地址时不伪装为 MP4 |
| 图文 | 有序完整图片列表、图片候选格式、动态图片标记 | 不将封面当正文、不把动态内容静默退化为静态成功 |
| CDN 与下载 | 精确主机、跳转规则、是否要求额外 Header/Cookie | 若无法满足调用方直链下载契约，停止并调整方案 |
| 运行资源 | 总用时、HTML 解压体积、跳转数量 | 超过现有预算先分析，不悄悄放大限制 |

真实网络验证不进入常规测试。后续至少对一条视频和一条图文验证受限字节读取，分别记录「页面取得」「解析成功」「媒体可读」；完整播放/图片完整性需调用方网络或 VPS 单独验收。不能将一个出口的成功描述为所有环境成功。

## 技术候选的使用边界

公开分享页内嵌 JSON 是首选研究路径。补充调研读取的第三方解析器源码提供了以下候选：移动分享页的 `window._ROUTER_DATA`，其中 `loaderData` 下的 `videoInfoRes.item_list`；另一种候选为 URI 解码后的 `RENDER_DATA`。可能的媒体映射包括 `aweme_id`、`desc`、`images[].url_list`、`video.play_addr.url_list` 与 `video.cover`。这些都不是四样本的实测结论；同一图片的 `url_list` 是候选地址集合，不能展开成多张正文图片。

具体状态变量、对象路径、类型值、播放地址字段与图片字段都必须由真实样本确认后才能进入解析器；第三方源码只帮助定位，不能代替当前平台证据。来源及版本记录见 [上游方案研究](../../.trellis/tasks/10-19-douyin-media-parser/research/upstream-options.md)。该研究也记录了官方授权 API 与任意公开分享链接需求的范围差异，不建议直接以其替代分享页解析。

2026-10-20 已按这些门槛完成本地实现与样本验收。实现没有加入登录 Cookie、验证码处理、签名逆向或第三方付费服务；目标 VPS 原生架构、出口与真实调用方下载仍需部署验收。
