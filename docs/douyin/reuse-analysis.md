## 可以复用

- 单 FastAPI 应用、单 worker、`X-API-Key`、8 KiB 请求体限制、健康检查。
- `success/data/error/meta`、请求 ID、缓存元信息、图片/视频/封面基本字段。
- 成功结果 TTL/LRU、按密钥限流、请求合并、取消清理、并发与等待容量。
- DNS 公网检查、地址绑定、TLS 校验、解压后体积限制、总期限和连接期限。
- 媒体不代理、不落盘的部署方式与离线测试习惯。

## 必须隔离

- 短链/详情页 URL 与作品 ID 规则、页面内嵌数据定位、内容类型判断。
- 平台相关请求头、登录/挑战/限流/删除页识别。
- CDN 精确主机清单、候选媒体字段、时长单位与视频格式判定。

复用的是稳定契约和处理机制，不直接把抖音 JSON 填入小红书 `noteDetailMap` 或复用小红书 CDN 假设。先用薄适配器包裹既有实现，避免为目录整齐一次性移动全部小红书模块。

2026-10-20 补充：受控服务端浏览器已纳入抖音获取候选。上述 HTTP 传输机制继续用于既有链路，但 curl 的 DNS/IP 绑定不能直接控制浏览器；浏览器出站、进程/上下文生命周期及资源预算须独立实现与验证，共用的是上层服务契约和总容量。
